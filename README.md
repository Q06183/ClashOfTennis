# Rally Club · 好友网球

手机浏览器优先的 3D 好友网球游戏。参考 Tennis Clash 的场上操作，采用独立自制场景和角色。没有充值、订阅、联赛、联盟或账号系统。

## 运行

需要 Node.js 22.12+。在项目目录运行：

```sh
npm ci
npm run build
npm test
npm start
```

打开 http://localhost:7470 。服务默认监听 `0.0.0.0:7470`，终端会打印网卡地址。手机与服务器电脑处于可互通的同一局域网时，在手机浏览器输入电脑的 Wi-Fi 地址和端口；不要把手机上的 localhost 当作电脑地址。

房主填写昵称后点「邀请好友」，把房号或邀请链接发给朋友。朋友加入后，两人都点「准备开赛」。如果房主使用 localhost 创建房间，分享给手机前请先改为通过电脑的 Wi-Fi 地址打开游戏，这样复制出的链接才是手机可访问的地址。

电脑必须持续开机且服务保持运行。公司/访客 Wi-Fi 可能隔离设备，VPN 网卡地址不一定能被朋友访问。局域网地址不是公网地址。

开发时分别运行：

```sh
npm run server
npm run dev
```

Vite 使用 5178 端口，并将 `/ws` 代理到 7470。生产服务同时提供静态资源、Brotli/gzip 压缩、`/health` 和 `/ws`。

## 操作

- **轻点地面**：指定跑位。人物会有限辅助接近来球，仍需手动击球。
- **向上滑动**：击球或发球。球从触球点沿屏幕手势方向飞出，长度决定深浅，速度决定力量。发球请斜向对角发球区。水滴线表示手势，击球后虚线与落点环表示预计飞行；碰网时预测停在网前。
- **短滑**：短球。**按住约半秒再向上滑**：高吊球。
- 靠近球网可以截击；接发球必须先落地。可在来球接近时提前滑动，击球指令缓存约 1.25 秒。
- 先到 7 分并领先 2 分获胜。发球需要进入对角发球区；一发失误后有二发，双误失分。发球等待上限 12 秒。
- 比赛中的 `?` 提供操作帮助。单人练习打开帮助会暂停，线上比赛不会因一人打开帮助暂停。
- 「♪」切换声音。手机浏览器需要首次触摸之后才可播放。

断线被识别后整场暂停，座位保留 30 秒，原标签页会尝试恢复。服务进程重启会丢失内存中的房间。网络完全中断但 TCP 尚未关闭时，通过心跳检测失联。

## 验证

```sh
npm test
npm run build
# 已运行 npm start 时，使用两个独立 WebSocket 客户端打完一场再重开
node --import tsx tests/network-play.ts
```

`docs/network-verification.json` 保存最近的完整网络对局验证结果。该测试只证明真实 WebSocket 协议及权威模拟，不能代替手机真机和异地网络验收。

## 公网交付

详见 [部署说明](docs/deployment.md)。需要一台可公开访问、允许长连接的服务器或容器平台，浏览器通过 HTTPS/WSS 访问。当前源码不依赖收费服务，也没有默认创建或购买服务器。

## 项目结构

- `src/simulation`：共享网球物理、触球、计分与 AI。
- `src/input`：触控与鼠标手势。
- `src/render`：自制 3D 球场、角色及镜头。
- `src/network`：快照接收和重连；客户端不决定比分。
- `src/ui`：首页、房间、HUD、结算、音效。
- `server`：权威对局、两人房间、静态服务。

开发进度及未验证项目见 [主验收清单](docs/MASTER_CHECKLIST.md)。目前不承诺与原作内部物理参数或手感完全相同，最终以用户真机对打反馈继续调校。
