# Kai：网球新角色 + 职业发球动作（真人动捕版）

用途：TennisClash（Rally Club）手机网页 3D 网球游戏。完全从零制作，没有使用文件夹里已有的 3D 模型。
风格参考：`competitorExamples/Photos`（卡通写实，白色球衣配亮色饰边、头带、运动鞋）。

## 动作数据来源（重要）
发球动作来自真人光学动作捕捉数据集 **Tennis-MoCap**，选用高水平右手男选手 jarua 的一次一发：
- Pulgarin-Giraldo J.D. 等，2017，LNCS 10125，pp.309–317，doi:10.1007/978-3-319-52277-7_38
- 数据集地址：https://github.com/jdpulgarin/Tennis-MoCap ，授权 **CC BY-SA 3.0**（再分发或使用需保留署名）
- 原始采样 100 Hz，重采样到 60 fps，取击球前 1.55 秒到击球后 0.95 秒，共 151 帧；按腿长比例 1.136 缩放到 Kai 的身高
- 骨盆、脊柱、四肢方向逐骨匹配源数据；肘、膝按铰链关节的弯曲面定扭转，逐帧方向误差 0.00°
- 动捕数据没有可靠的手腕和拍面信息，以下部分是按生物力学规律补的（不是原始数据）：握拍的大陆式手指姿态、肩部最大外旋后的拍头下坠、击球瞬间的前臂内旋、球拍加速到击球帧（拍头峰值 38.0 m/s）、抛球抛物线和击球后的球路

## 制作步骤与关卡
1. **定规格**：游戏角色，右手持拍，平击一发，平分区（deuce 区）发球。
2. **找参考**：风格参考同目录截图；动作参考改为真人动捕数据（见上）。
3. **身体底模**：MPFB（MakeHuman，CC0）参数化人体，男性运动员体型，身高 1.865 m，头部略微放大以贴近游戏风格。
4. **服装和道具**：衣服从身体表面克隆，共用蒙皮和布线；饰边沿边缘环生成，下摆水平切。球拍按 ITF 标准：长 68.5 cm。
5. **绑定骨骼**：游戏引擎标准骨骼加上臂、前臂扭转骨；每顶点最多 4 根骨骼、权重归一化；大陆式握拍由程序求解。
6. **重定向上衣不破损**：举手过头时 90% 的上臂扭转由扭转骨承担，上衣权重做 4.5 cm 空间平滑。
7. **做动作**：动捕重定向 → 腾空段按全身重心的自由落体抛物线修正（g = 9.81）→ 击球前球拍滞后和内旋按发力链补齐 → 脚部接地求解。
8. **质检和导出**：逐帧做物理检查（`qa/physics_report.json`），导出 GLB 后重新导入验证，再构建单文件 HTML 预览。

## 质检结果（真人动捕版）
| 检查项 | 结果 |
|---|---|
| 脚着地时是否滑动 | 左脚最大 1.4 mm/帧，右脚 0.7 mm/帧 |
| 鞋底是否穿进地面 | 最低点在地面以上 0.6 mm；腾空 14 帧双脚都离地 |
| 腾空是否符合重力 | 按全身重心拟合 g = 9.87 m/s²（真实值 9.81），腾空 0.25 秒 |
| 发力链顺序 | 膝第 89 帧 → 骨盆、躯干第 90 帧 → 上臂第 91 帧 → 前臂第 93 帧 → 球拍第 94 帧（击球帧） |
| 关节角度 | 右肘 1.5–109°，膝 4–96°，右腕 11–74°，没有反关节 |
| 骨骼长度 | 误差 0.001 mm |
| 击球 | 击球点高 2.70 m（头顶上方约 1.05 m），骨盆前方 20.5 cm；拍头峰值 38.0 m/s 在击球帧，击球瞬间 37.3 m/s，职业区间 35–50 m/s；拍面正对球网 |
| 抛球 | 最高点约 3.43 m，击球前 0.38 秒到达顶点；出球 173 km/h，过网高出 19 cm，落入对角发球区 |
| 重心平衡 | 双脚站立阶段重心偏出支撑面最多 9.1 cm，在 10 cm 限内 |
| 球拍和身体 | 全程 0 帧穿模 |
| 网格变形 | 发球全程 99% 的网格边长：身体 ≤ 1.35 倍、上衣 ≤ 1.93 倍；身体、上衣各有极少数极短袖笼边最大拉伸约 3–5 倍，正常视角不可见 |

## 已知局限 / 下一步
- 手腕/拍面和击球后球路是生物力学重建，不是动捕原始数据；要更真实的拍面控制需要带手部标记或 IMU 的数据集。
- 这个模型还没接进游戏。游戏现在用 16 骨骼的 `direct-original-v1` 格式，接入需要写骨骼映射或适配层。
- 单次发球是循环片段，还没有站立、走、跑、其他击球动作；要做系列动作可以复用这套动捕重定向管线。
- 近景特写前建议再精修一遍袖笼权重。
