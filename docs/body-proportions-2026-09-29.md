# 修订3：上臂轴线与全身比例

范围：林岳、梅岚、诺亚三个样板。用户要求修正弯曲上臂、手掌/手腕
比例以及手臂/腿/躯干比例。未修改正式比赛角色 URL 和其余七人的模型。

## 根因与校正

- 原模型共享骨骼坐标，却不共享皮肤表面中心。例如右上臂
  1.24m 高度附近，林岳表面中心约 x=-0.420,z=-0.089，诺亚约
  x=-0.389,z=-0.046；骨骼轴并不位于这些表面中心。
- 最初怀疑上臂中段混入大量前臂权重；实测该项并非主要问题，
  已在沟通中更正。主要校正是将各角色截面中心重新对齐直线骨段，
  然后把肘附近的权重过渡约束到解剖关节处。
- `body-proportion-calibration.py` 按不同角色源截面处理，上臂只减去
  偏离轴线的位移，保留截面厚度、肌肉不对称、衣袖与连续皮肤。
  没有圆柱替身，没有切掉手臂，也没有删除原始手指三角面。

## 当前样板尺寸

这些是本地美术校准值，不是从透视录像恢复的精确人体测量。

| 项目 | 修改前 | 修订3 |
|---|---:|---:|
| 上臂控制长度 | 0.36m | 0.33m |
| 肘到握拍点（含腕掌部分） | 0.31m | 0.34m |
| 肩到握点最大总长 | 0.67m | 0.67m，不变 |
| 中立髋部高度 | 0.85m | 0.96m |
| 大腿/小腿控制长度 | 0.37/0.37m | 0.425/0.425m |
| 林岳手掌局部缩放 | 1.00 | 0.88 |
| 梅岚手掌局部缩放 | 1.00 | 0.90 |
| 诺亚手掌局部缩放 | 1.00 | 0.86 |

腿部采用同一个连续身高映射处理皮肤和绑定矩阵：抬髋、提高膝位、
压缩髋到肩段；脚底、肩部、头顶的高度保持锚定。没有全局拉伸角色。
手掌与腕的衔接随新皮肤校准，腕点仍在握点近端，避免长腕接小手。
更换回非样板球员会恢复旧控制长度，不残留新腿长。

## 验证结果

- **421/421 全量测试通过**；生产构建通过；`git diff --check` 通过。
- 上臂源截面、上臂中段权重、各控制长度、绑定姿态误差、左右手/
  双端、20/30/60fps、原拍头路径一致性均有自动检查。
- 新样板实际蒙皮在跑动、正反手、发球、脚落地救球中有限、接地；
  不依赖包围盒遮掩三角面：另有完整索引边拉伸检查。
- A姿态及前/侧面击球浏览器截图已核查。新预览支持「比例检查 ·
  A姿态」和「骨骼轴线」；修改前/后使用相同相机，不改变图片宽高比。
- 三份 `.blend` 和样板头像已更新；没有新生成积分支出。

证据：`artifacts/body-proportions/` 中的 `sections.json`、
`proportion-tests.log`、`regression.log`、`build.log`、`blender.log`、
`proportion-comparison.jpg` 与单角色截图。
源/输出哈希与尺寸记录在 `assets/characters/hand-face-prototypes.json`。

## 仍需明确的边界

- 肌肉/袖口仍有正常弧面；“上臂直”是骨段与主体中心线不出现多余折弯，
  不是把轮廓削成直线或圆柱。
- 原手指网格粗糙、包握闭合与脸部贴图清晰度仍未达到参考质量。
  本轮没有把这些旧问题标为完成。
- 三名样板的比例是待用户审美验收版本，不代表全角色已批准上线，
  也没有完成真实手机性能/观感验收。
