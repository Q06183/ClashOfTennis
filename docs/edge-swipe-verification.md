# 底线 / 场底边缘滑动方向修复

日期：2026-09-28

> 历史记录：本轮“前 100 ms 方向”仍未满足完整落点方向，已被 [全场落点与镜头修复](whole-court-aim-verification.md) 取代。下文数字只支持当时的短时角度条件，不代表全程方向已正确。

## 复现与根因

普通回球使用只含 x/z 的地面投影；实际球在非零高度，且球速、重力、过网约束改变初始飞行弧线。视线较低、靠边站位及高速高点击球时，地面方向并不等于屏幕所见出球方向。

真实 Match + 当前相机的复现：无名站 x=5.8、z=12.4，触球 x=6.2、y=2.4、z=12，手势 dx=90、dy=-150：

- 修复前初始出球角比手势多偏约 22.93°，目标 x=6.57（出界）。
- 修复后角度误差低于 0.01°，目标 x=3.93（场内）。
- 场底 z=16 的相同手势从约 19.55° 偏差修正为低于 0.01°；该手势仍可合理出界，不把落点截回场内。
- 两座位对称，记录见 `artifacts/edge-swipe/measurements.json`。

## 修复

- `captureSwipeAim` 额外保存输入时相机的三个高度投影系数 `elevation`；服务器验证并复制，旧客户端没有该字段时仍按旧方式处理。
- `directionForFlight` 在**实际触球点**求解前 100 ms 球弧的屏幕方向，使用实际力度、体力、属性倍率、过网 / 飞行时间约束和球种减速，选择与滑动朝向一致的解。
- 延迟预设击球继续使用输入时的相机与手势，在真实触球位置求解，不用来球当时的位置替代。
- 切削和救球仍有既有随机散布，不消除技巧差异。不修改发球求解、深度档位、计分、出界规则、角色属性或无名 ×10 增益。
