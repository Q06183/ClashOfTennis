# 双打电脑换球员修复

时间：2026-09-30 17:55（Asia/Shanghai）。

## 原因与修复

- 原电脑席位只有添加/移除，添加时统一使用本地练习对手。服务端已有按席位配置电脑角色的能力，但房间缺少入口。
- 房主现在可以在每个电脑位点击“更换球员”，复用角色面板并显示目标队伍/席位。
- 点击角色只更新草稿，确认才向服务端发送配置；关闭取消，不改本人、练习对手或其他电脑。
- 确认前重新检查房主身份、电脑席位、比赛锁定。房间广播不打断有效选人草稿，目标移除后退回房间。
- 复用现有服务端配置、准备状态清除和广播流程，无服务端改动。
