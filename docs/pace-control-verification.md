# 普通滑动容错与速度风险（2026-09-29）

用户要求：普通滑动不要过分敏感，越快的球才越容易出界。本轮明确改变先前“所有力度严格保持原始角度”的规则：触控回球按力度提供平滑的边线／底线辅助。

## 实现与范围

- 回球使用验证后的原始手势力度计算辅助，而不是按角色属性高低；自动高压提升力度不会取消玩家原本选择的普通球容错。
- 力度≤0.38时完整辅助；0.38～1之间平滑递减，满力度为0。无随机方向误差、无速度档位突变。
- 横向落点在中间±2.6米不改；超过后用连续、单调的软边界逐渐收敛，完整辅助时不超过±3.9米，留出单打边线余量。
- 纵向8.5米内不改；超过后向10.7米软上限收敛，完整辅助留出底线余量。速度越大，越保留原来的过深／过宽结果。
- 先算辅助后的深度，再求球路；横向辅助后不重新更改飞行时间，避免引入之前的方向求解循环问题。真实球物理落到调整后的目标，不是仅修改落点提示或出界判定。
- 中央方向、小球落点深度、自动救球、0.5秒补滑窗口及胜利庆祝不变。救球／切削的随机深度先结算，再按手势力度提供落点辅助。
- 当前只应用于带屏幕投影的触控回球。发球仍需主动斜划进对角区，不自动纠正发球方向；无投影的AI与旧客户端保持旧规则。
- 手势提示显示“稳健落点／注意控线／高风险压线”；帮助明确慢球边缘辅助会主动收敛角度，不再暗示慢球始终与原始手势同角度。
