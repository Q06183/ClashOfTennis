# 2026-09-29 出球方向、救球与体力修订

## 本轮规则

- 保留正后方近／远景按钮、默认近景和选择记忆；两档同一机位，近景只做1.9倍缩放。没有重新缩短球场或放大人物。
- 发球和回球依据实际球拍触球位置、当前镜头投影、飞行速度及重力，求解出球方向。删除求解之后额外叠加的身体正前方补偿。
- 方向验收直接投影真实出球的前100毫秒，不再反向抵消旧补偿。各位置、双端、两档视角、球种和球速均覆盖。球的后半程仍受重力影响，不承诺整条屏幕轨迹为直线；切削和救球仍保留既有随机散布，不强制把出界球夹回界内。
- 普通站位、正在执行的跑动或自动接球路线存在合法接球窗口时，不抽救球概率；否则才搜索左右侧扑。人物前后位置不因侧扑改变。接发必须先落地，二跳/出界后不允许救球。
- 保留此前确认的总体力概率：满体力90%，1/3及以下10%，中间平滑过渡；每次来球只抽一次。
- 每分初始体力＝上一分结算后的总体力；分内喘息不超过此初始值。消耗折算20%、单分最多扣总体力20个百分点，分末返还实际扣费的角色比例且不超过90%，均不变；一发失误后的二发不重置。
- 持拍手够球、侧向腾空、翻转趴地、双手支撑起身。约0.48秒落地，0.68秒开始起身，1.18秒恢复操作，起身过程恰为0.5秒。高球保持更高的肩部位置，避免侧倒后球拍够不到。左右手使用完整的根节点镜像，而非仅镜像局部缩放。

## 发现并修复的问题

1. 旧瞄准测试先撤销身体补偿再测角度，无法证明实际球路。现在统一使用 `projectedOutgoingAngle`，直接从真实球速度测量，并从延迟快照还原起始速度。
2. 根节点侧倾后，左手球员仅设置负缩放不能正确镜像旋转；增加完整镜像，使实际球拍触球误差仍保持10厘米以内。
3. 趴地阶段高压拍柄穿过IK解的反方向，导致突然翻拍；落地前渐变为肩到拍头的轴向，并保留手腕世界朝向。
4. 将局部轴对齐包围盒旋转到世界空间会把不存在的空角算到地下。现在按实际蒙皮顶点检查，并将允许最低高度从-0.30米收紧到-0.12米，不用放宽阈值掩盖穿地。
