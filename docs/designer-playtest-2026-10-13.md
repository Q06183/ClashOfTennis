# 设计师试玩评审 · UI 与玩法改进建议（2026-10-13）

## 试玩范围与方法

- 版本：main `9f78343`，本机 `http://localhost:7470/`（服务 `/health` 正常）。
- 视窗：桌面 1280×960 看首页；其余在 390×844 移动端模拟（触控模拟开启）中完成。
- 实际走完的流程：首页 → 球员页（选拉斐）→ 快速匹配（等待约 23 秒）→ 单人练习配置 → 新手引导全部 7 步 → 「继续和机器人对打」轻松难度打完一整场 → 结算与复盘 → 好友对战面板。
- 截图：`artifacts/designer-playtest-2026-10-13/01–18*.png`。
- 局限：手势由脚本执行（速度和角度比较机械），所以本场 0:7 只能说明体验链路，**不能当作难度平衡的证据**；没有在实体手机上测试，也没有做真人双人测试。
- 与 10-12 两轮评审的关系：触控尺寸、暂停、复盘、发球区高亮这些已经修好，这里不重复提。本文关注的是**还没有覆盖到的体验问题**。

## 一、试玩中观察到的事实

| # | 场景 | 观察（证据） |
| --- | --- | --- |
| F1 | 快速匹配 | 主按钮进入后只有“正在寻找对手…”，等了 23 秒既没有预计时长、在线人数，也没有电脑兜底。服务端 `server/rooms.ts` 只撮合真人。 |
| F2 | 球员页 | 9 名球员中 6 名的标签都是“右手 · 双反”，区分度很低；详情直接显示“正手球速系数 +26.4%、反手 -35%……分末恢复返还本分已扣总体力的 50.4%（最高 90%）”。 |
| F3 | 用词 | 单人练习里管对手叫“人机搭档 / 练习搭档”，双打里“搭档”指的是队友；默认昵称“球友”同时又是匹配对手的称呼。 |
| F4 | 教学 HUD | 教学时顶部依次叠着：比分 + 两组体力（本分/总体）、元信息条、7 个步骤标签、4 句长说明卡，占屏幕高度约 35%。“滑动越快，出球越快；相同用时划得越长也更有力……”这段在发球、接球、切削三步里原样重复。 |
| F5 | 教学点按 | “点这里”的文字在手指图标下方；我点在文字上，两次都没触发回位，改点手指上方的标记才成功（`.tutorial-hand` 范围是 y 536–596，文字在约 598 以下）。 |
| F6 | 教学失败 | 第一次接球没成功，提示从“已回击，等待合法落地”直接跳回原来的说明，没有明确说是出界、下网还是太短。 |
| F7 | 教学结束 | 第 7 步“赢下比赛”没有真打，0:11 时直接判 7:0 完成。结算显示“最长回合 7”，和实际不符。 |
| F8 | 对打提示 | 底部提示每拍都在变（“来球了，可以提前向上滑动 / 击球已准备 / 好球！轻点球场… / 慢球辅助留边 · 越快越需要控制角度和长度 / 短慢划放小球 · 长按上旋”），大约每 0.5–1 秒换一次，打球时根本来不及读。 |
| F9 | 得失分结构 | 轻松难度下随便往上滑也能打出 10 拍；丢分来自 3 次出界、2 次漏接、2 次发球超时（超时是脚本造成的）。本方 11 次回球、8 次合法落地，但**没赢下一分**——没有能主动“打穿”对手的手段。 |
| F10 | 结算 | 输球时最大的标题是“MATCH WINNER 练习搭档 · 林岳 / 获胜方庆祝中 · 持拍庆祝”（把动作名称直接露给了玩家）；最有价值的复盘默认是折叠的；“11 / 8 实际回球 / 合法落地”这种斜杠写法不好读。 |
| F11 | 场上按钮 | 高吊是右下角的一个开关按钮（“下一次向上滑生效”），和其他靠手势出球的方式不统一。 |

## 二、UI 改进建议

### U1 用词统一（P1，成本低）
- 单人练习：对手统一叫“陪练 / 对手”，“搭档”只用于双打队友。
- 默认昵称不要用“球友”，改成“你”或“玩家 + 随机两位数”；匹配中的对手占位用“等待对手”。
- 赛制文案：“抢七 · 先到 7 且领先 2 分”→“7 分制 · 需领先 2 分”。“抢七”是术语，新手看不懂。
- 结算副标题去掉“持拍庆祝”这类动画名称。

### U2 场上信息减负（P1）
- 体力：每人只显示一根细条（总体力），“本分”的变化做成条上的浅色缓冲段，去掉 4 个百分比数字。
- 底部提示分级展示：
  - 前 3 分：完整文字；
  - 之后：只在出现**新情况**时显示（第一次遇到上旋来球、体力低、击球已缓存），每条至少停留 1.5 秒；
  - 普通来球不再出文字，改成球员脚下击球环的颜色或脉冲。
- 教学卡：每步只留**一句动作指令 + 一个示意动画**。力度/深度的物理说明只在第一次出现时显示，后面可以点“为什么？”展开。7 个步骤标签缩成一根进度条加“3/7”。

### U3 教学引导精度（P1）
- 点按引导：命中区域应覆盖手指图标加文字整块；或者把文字移到手指上方，让地面上的目标环成为唯一视觉焦点。
- 每次失败都给明确原因和修正方向：“出界 → 划短一点”、“下网 → 划长一点”、“没碰到球 → 先点按跑到球的落点附近”，并在场上标出这次的实际落点。

### U4 球员页可读性（P2）
- 详情改为**和平均值对比的六维雷达图或差值条**（正手 +22 用绿色、反手 -14 用红色），数字保留但不再写成百分比系数。
- “+26.4% / 50.4%（最高 90%）”收进“这些属性如何影响比赛？”的展开区。
- 卡片第二行把重复的“右手 · 双反”换成各自的招牌特点（例如“重炮正手”“网前快手”），握拍信息改成一个小图标。
- 点卡片后，详情改为**底部抽屉 / 固定在底部**，不要把列表滚走（现在点了卡片页面会滚到详情位置）。

### U5 结算页（P2）
- 输球时以“你”为主角：主标题写进步，例如“最长回合 10 拍 · 8 次合法落地”；对手庆祝动画留在背景里，不放大标题。
- 复盘默认展开第一条：“本场最多的失误：出界 ×3 → 下一场：划短一点、往场内收。”
- 数据改成并列小卡：回球 11、合法落地 8（73%）、出界 3、下网 0，不用斜杠。
- 显示和个人最佳的对比（系统已经按本机保存）：“最长回合 新纪录！”。

## 三、玩法改进建议

### G1 快速匹配兜底（P0/P1，影响首次留存）
主 CTA 现在很可能是死路：好友游戏的同时在线人数天然很少。建议：
- 匹配等 10 秒后显示“先和电脑打一场”按钮；20 秒后自动用电脑补位开赛，有真人进来时下一场再匹配真人；
- 匹配框里显示“当前在线 N 人 / 已等待 0:12”；
- 或者把首页主按钮改成“开始打球”，进去后再选匹配、电脑或好友，避免把玩家导进空房间。

### G2 给“进攻”一个回报：击球时机评价（P1，核心手感）
现在得失分几乎全靠对方失误（F9），玩家没有“打出一记好球”的爽点。建议在已有“缓存击球、到位自动回击”的基础上加一个**击球时机窗口**：
- 球进入击球区时，脚下的环收缩；滑动或自动出手时，根据时机落在 早 / 好 / 完美 三档；
- “完美”带来球速 +X%、可用角度更大、自动辅助留边减少，并配专属音效、球拍闪光和“PERFECT”气泡；
- 对手被迫跑动太远时，就出现真正的 winner（制胜分），结算里统计“制胜球”；
- 这只改变已有击球参数的系数，不需要新手势，和现有物理模型兼容。参数要用平衡脚本和实机反馈再调。

### G3 教学的最后一步改成真打（P1）
- 把“赢下比赛”换成“和陪练打 3 分，赢 1 分即可通过”（陪练降速、只打你的正手），让玩家真正体验一次得分；
- 不再显示假的 7:0；结算写“教学完成 · 你赢下了第一分”。

### G4 难度曲线与陪练行为（P2）
- 轻松陪练应该让新玩家**平均能赢 2–3 分**（建议目标：首场 30–40% 的分能赢），而不是只“让回合变长”。可以在 `relaxed` 档下加一个概率：回球偶尔偏短或偏中路，留出进攻机会；
- 按本机最近 3 场的结果动态微调陪练（连输就松一点，连赢就提示“试试认真对打”）。

### G5 练习目标升级为“场地小练习”（P2，复玩）
- 在现有“稳健回球 / 长回合 / 多样球路”之外，加入**场上目标**：对方场地出现目标区（角落方框），打进得星；切削练习、发球外角练习各做一关；
- 每关 3 星，本机记录；完全免费、不要账号，和产品定位一致。

### G6 高吊改用手势（P2）
- 去掉右下角的“高吊”开关，改成**向上滑后在末端弯钩 / 双指上滑 / 短促长滑**其中一种；保留按钮作为“辅助模式”选项。这样所有球种都走同一套手势，场上也少一个按钮。

### G7 好友对战的社交感（P3）
- 房间里加入预设快捷表情（“好球！”“再来！”），对局里用表情气泡；
- 结算后“再来一场”默认交换发球权，并显示双方的历史胜负。

## 四、优先级建议

| 优先级 | 项目 | 理由 |
| --- | --- | --- |
| P0/P1 | G1 匹配兜底 | 首页主入口会把新用户卡在空等 |
| P1 | U1 用词统一、U2 场上减负、U3 教学精度、G3 教学真打 | 都卡在首次体验链路上，成本中低 |
| P1 | G2 击球时机评价 | 决定“好不好玩”的核心爽点，需要调参 |
| P2 | U4 球员页、U5 结算页、G4 难度、G5 目标练习、G6 高吊手势 | 提升理解和复玩 |
| P3 | G7 社交表情 | 锦上添花 |

## 五、建议的验收指标（做实验用，当前没有数据）

- 首页 → 开始第一场对局的转化率；匹配等待超过 20 秒的流失率。
- 教学完成率；完成教学后进入第二场的比例。
- 轻松难度首场：玩家赢分占比（目标 30–40%）、“完美”击球占比。
- 结算页“再来一场”的点击率。
