# 球员体型、服装与随挥验收

日期：2026-09-23。基线：`5acf3fe`。九名现有角色，沿用已拥有的模型，外部生成积分为 0。

## 修改与原因

- 模型上臂、前臂、大腿、小腿局部增加自然肌肉体积，关节位置不变；不同角色体积系数为 0.055–0.12。报告见 `assets/characters/refinement-report.json`。
- 九套服装分别保留米白、青绿、铁锈红、蓝、紫、深绿、海军蓝、铜色和梅紫风格，加入侧片与细条纹。精细图案按表面坐标生成到原 UV 贴图，沿源服装颜色边界过渡，避免按整个三角面涂色造成锯齿。头像使用最终 GLB 重渲染。
- 护腕为 48 顶点，绑定 canonical `LowerArm_R`；左手角色由运行时整体镜像，护腕自然跟随持拍手。
- 原模型前臂约 0.229m，运行时约 0.31m；单独映射肘腕而不适配段长，会把蒙皮拉成细长缝。现在按固定 IK 肢段长度匹配源骨骼，并平滑肩、肘、腕及腰部权重。
- 领口、肩部不再跟随追踪球位置的头部转动；手掌旋转相对前臂限制在 0.95rad 内，缓解不合理的腕部扭曲。握点和实际拍面接触位置保持原有约束。
- 双反握拍由离散臂长候选改成连续球面约束求解，消除连续挥拍中手腕约 14cm 的跳变。所有球员正反手使用转肩蓄力、前伸、随挥收拍；单反保留另一手向后展开平衡。

## 验证

- 完整回归：252/252，包含真实 WebSocket 双客户端击球、房间和原有接球/缓存/救球判定。
- 新增实际模型检查：骨骼端点吻合，头部不会拉动领口，双反 2001 相位双手连续性，九名球员护腕刚性与骨骼绑定，六类挥拍各 21 相位的实际蒙皮边长。
- 严重变形指标使用 `变形后边长 / max(0.025m, 原边长)`，仅筛选手臂相关蒙皮边；阈值 4。该指标用于捕捉局部三角形异常，不是整条手臂长度比。原版九模型诊断峰值约 4.29–5.15，修复后约 2.63–3.70。
- 独立复核：护腕 162/162；连续握拍求解另以 1500 个随机场景与密集方向采样比对，未发现约束/最优性错误。
- 九名真实 GLB 浏览器检查：准备姿势、反拍侧面随挥、正手背面随挥；发球关键帧在本轮前续工作中检查。检查覆盖的画面未见手臂爆炸、护腕脱离或拍面位置跳动。
- 最终材质修正后重跑真实模型检查25/25；正式7470在390×844画幅下加载新角色、头像和服装，滑动输入可进入得分/下一拍预设状态，无浏览器error。本次未将有限手动输入检查当作完整真机对打验收。
- 构建：TypeScript、Vite 和预压缩通过。运行时代码构建为 `index-DN22853s.js`。

不改变模拟层的能力数值、速度、体力、触球判定、球路与联机协议。浏览器画幅检查不等于真机体验验收；用户仍需在手机上复打，评价动作是否自然。

## 重现资产

1. 将基线 `5acf3fe` 的 `public/models/athlete.glb` 和 `public/models/characters/*.glb` 放在一个独立输入目录，保持相对路径。不要使用已精修的输出作为输入。
2. Blender 5.2 后台执行 `scripts/assets/refine-athletes.py -- <输入目录>`。
3. 完成后执行 `scripts/assets/render-athlete-portraits.py`。
4. 运行 `npm test` 和 `npm run build`。正式服务 7470 会读取新的 dist；此次无需重启服务或清空房间。

可编辑源保存在 `assets/athlete/rigged/athlete-refined.blend` 和各角色目录。
