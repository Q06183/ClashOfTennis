# 自己的标识与双打同侧高远球

提交：`c63b557`。只包含本轮修复，未包含并行聊天的电脑选角改动。

## 修复

- 自己脚下使用高对比荧光黄绿色粗环及深色外边，头顶显示同色小三角。
  小三角按屏幕14px缩放，单打、双打、换边及重连均按实际本地座位跟随；
  首页及结算隐藏，不依赖发球员或最后击球人。
- 双打接球责任不再只比较预计落点距离。高远球先判断是否有真实可达的高点，
  允许前场球员提前后撤到扣杀位置；无法高点处理时改走落地后接球路线。
- 高远球落在同侧后场且同侧球员来得及时，优先由该球员后撤接球，
  不再一律要求异侧后场搭档横穿补位。
- 普通后场搭档更适合接球时，前场球员后撤覆盖，而不是在网前保留旧目标。
  仍保留手动移动优先、接发指定球员、实际球拍触球和体力/惯性限制。
- 没有扩大臂长、跳高、球拍范围或增加瞬移；高点用现有扣杀动作，
  不够高或来不及则正常后撤回击。
