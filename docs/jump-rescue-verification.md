# 体力驱动的四类跳身救球

日期：2026-09-28

## 规则与概率

用户先要求四种明显跳接动作，随后将固定 30% 改为按体力平滑变化。最终实现：

| 当前体力 | 跳接抽中概率 |
|---|---:|
| 满体力 | 60% |
| 2/3 | 32.5% |
| 1/2 | 13.59375% |
| 1/3 及以下 | 5% |

`t = clamp((stamina - 1/3) / (2/3), 0, 1)`，`p = 0.05 + 0.55 * t² * (3 - 2t)`；两端一阶斜率为零。以符合救球资格时、扣除 0.1 起跳体力前的当前体力为准。无输入、普通跑动可接、超出跳接范围、未落地接发球、二跳或已判出界时不抽签。每次来球仅抽一次，重复滑动不能提高机会；抽中后仍要实际触球。

## 触发与动画变化

- 旧版约 0.5–1.65m 高度、1.8m 跳步限制以及低体力完全禁用，使跳接罕见；反手侧还误用了正手目标站位。
- 新候选高度 0.35–3.05m，跳步最多 2.5m；去掉低体力硬禁用，改用 5% 概率下限；正确处理利手和反手侧。
- 四类 `stroke` / `backhand` 由服务器决定后同步，客户端传入伪造字段不改变选择：
  - 正手：侧向跳步、转肩引拍、前伸与对侧随挥，根节点最高升起 0.34m。
  - 反手：跨步侧转、单手伸拍及辅助臂反向平衡，最高升起 0.34m；常规双反不变。
  - 截击：短引拍、腾空挡击、短随挥，最高升起 0.38m。
  - 高压：头顶伸拍、剪刀步腿部交换、向前下方随挥，最高升起 0.62m。
- 位移约 0.20s，最少腾空 0.10s 后允许触球，完整恢复 0.78s。固定手臂骨长不变，命中仍要求实际可达，不直接把球拉到球拍。
- 救回球仍降速、随机偏移，可能出界；不会把跳身高压伪装成普通满威力高压。
- HUD 优先显示具体跳接动作，避免被“已预设击球”覆盖；显示当前体力概率与适用条件。

## 参考与来源边界

实际读取并保存以下公开资料：

4. Feel Tennis：[Volley and Smash](https://www.feeltennis.net/volley-and-smash/) — 仅公开页面说明的高压控球、脚步和困难情境调整，未购买或使用付费课程。

跳身路径和剪刀步为本地独立编排的游戏动画，不是某运动员动作的逐帧复刻或动捕。尝试访问的部分 USTA/高压直链返回 403/404，没有当作成功读取的依据。
