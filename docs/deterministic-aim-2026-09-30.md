# 出手方向稳定性修复（保留切削落地偏转）

2026-09-30，用户要求检查梅岚低发球属性导致容易偏角的问题；
随后明确：**切削落地后的随机横向转向要保留**。

## 最终规则

- 发球、正反手、截击、高压、高吊、上旋、切削出手、救球出手：
  不增加随机横向或深度散布。旧 `aim`、`directionX`、仅地平面投影、
  完整相机投影输入都使用相同边界。
- 相同触球点、镜头、手势、球种与力度下，球员属性/体力不改变目标落点
  和球场平面方向；仅改变实际飞行时间、球速和竖向弧线。
- 梅岚发球属性仍为 42，发球速度系数仍为 .55，保留高慢球弱项。
- 切削首次落地之后，保留原随机转角 ±.16rad（约 ±9.17°）、
  .80～.92 水平速度倍率、.58～.78 竖向速度倍率，仍由服务端统一抽取。
- 救球成功概率继续按总体力抽签，不是方向误差，不予删除。
- 保留主动选方向、快速击球的出界风险和普通回球落点辅助；
  发球仍需主动打进对角发球区，不自动代选方向。

## 原因与修复

1. `match.ts` 中切削/救球仍采样二维落点扰动。完整触控路径虽然不使用
   横向散布，随机深度仍可能间接改变投影换算；旧输入路径还直接加横向散布。
2. 实际球速和体力影响 `flightTime`，原逻辑随后拿这个飞行时间倒算
   “前100ms看起来沿手势”的横向速度，结果换球员会变更横向落点。
   重现同一手势时：梅岚 targetX -2.0045m、林岳 .1244m、里奥 .6719m。
3. 改为先用林岳满体力中性飞行作为瞄准标定，再应用实际属性/体力影响
   真正的飞行时间。保留中性角色原控制标定和球种规律。
4. 移除出手随机横向/深度散布及旧输入的伸手距离横向惩罚；
   切削落地随机偏转保持原始数学公式不变。

注意：不同高度弧线在透视画面中的瞬时斜率可以不同，这是竖向抛物线投影，
不是球场平面的随机偏转。不能为了强行保持相同屏幕瞬时斜率再次移动落点。
