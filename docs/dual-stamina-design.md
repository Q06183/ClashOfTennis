# 单分体力与总体力

日期：2026-09-28

## 规则

- 每位球员有 `stamina`（本分条）和 `totalStamina`（总体条），范围均为 0–1。
- 一场新比赛两条均满。每个新得分回合仅重置本分条为 1，总体条保留；一发失误后的二发不是新的一分。
- 跑动、击球和起跳消耗统一经过账本：本分实际消耗 ×0.2 扣总体力。一分累计最多扣 0.2；本分条暂时喘息恢复后再次消耗，不增加该分的 20% 预算。
- 分结束时，基准返还率为 60%，乘角色现有恢复系数，最高 90%。返还对象是**该分实际扣掉的总体力**，不是历史疲劳或总体力上限。
- 每分仅结算一次，包括最后得分、断线结束；未消耗不返还。总体力不足时只按实际扣除额结算，不能凭账面成本刷出体力。
- 分间等待不继续增加返还；本分条可在回合内按旧静止恢复率喘息，但不恢复总体条。
- 有效体力＝本分体力×总体力，用于跑动速度、实际击球力量以及接球预测。后续用户修订：救球概率仅使用总体力，满值90%、1/3及以下10%，详见 [六项修订](six-fixes-verification.md)。

## 例子

林岳耗尽一条本分体力：总体力扣 20 个百分点，分末返还 12，净损失 8。梅岚恢复系数 1.32，返还率 79.2%；无名原恢复系数 1.78，但被封顶至 90%，净损失至少是本分实际总体消耗的 10%。

## 界面与同步

- 比分板双方各显示“本分”和“总体”两条独立体力条及百分比，总体条用蓝色区分。
- 球员详情直接显示角色分末返还率，并说明 20% 折算、90% 上限、二发和有效体力。
- 网络快照包含两条体力与单分账本；同分内可插值，跨得分不混合。旧快照缺失总体条视为 100%，不保留陈旧账本。
- 所有计算在共享权威模拟中完成；客户端不能提交体力值。
