# 新手实操引导与单人练习

## 实现

- 单人练习包含并列的「新手引导」「轻松对打」「认真对打」，切换难度不残留引导状态。
- 引导顺序：发球站位移动 → 发球 → 第一次普通接球 → 跑动回位 → 第二次普通接球 → 切削 → 人机认输、玩家获胜。
- 操作时暂停并等待用户；发球须合法落地，回球须实际触拍、越网并合法落地才算成功。普通接球成功 **2 次**，不是 200 次。
- 接球失误恢复当前来球检查点，不回到发球；切削失败也只重试当前来球。
- 引导展示循环手指动画，并标注滑动与出球方向。普通回球及发球同向，切削反向；文案解释滑动速度、距离与球速、深度的关系。
- 完成标记版本为 `rally-tutorial=3`，只在玩家获胜后写入。自由练习与重玩引导均可随时选择。

## 首页约束

用户明确要求：单人练习入口留在原来的底部位置，只稍微加强可见性，**不可上移或抢占其他按钮位置**。

最终只使用浅绿色底色、细边框与略加粗文字，保持原按钮高度和菜单布局。菜单顺序仍为快速匹配、单打开房、加入房间、双打开房、球员选择、单人练习。
