## 实际修改

- 为三人输出 `public/models/prototypes/{lin,mei,noah}.glb`，以场景 extras
  `handFaceRevision=1` 启用独立腕掌适配；其他模型行为不变。
- 腕点位于握拍点向肘部方向 0.065m；变形前臂长从约 0.31m 缩为
  0.245m，保留原游戏 IK、拍头位置和触球范围。它不是缩短比赛物理手臂。
- 原低分辨率手/前臂存在不规则切口，仅局部挪动权重无法消除尖片；
  样板改用闭合渐细前臂、腕部过渡、掌心、四指和对握拇指表面。
- 两手分别有握拍/放松形态；支撑手接近第二握点时过渡为包握。
  左右手几何分别镜像，再随人物整体惯用手镜像，不只换拍子的父节点。
- 五指用合并几何与形态目标，额外可见网格为 11 个，而非每节手指
  单独绘制的 37 个。仍不是完整手指骨骼/碰撞或表情捕捉系统。
- 脸部局部拓宽/圆润、眼周比例微调、颧颊与下颌平滑，
  柔化烘焙阴影，降低皮肤镜面感。保留发型、服装、肤色差异。
- 原始网格的 UV 重复顶点按同位置邻域平滑，避免开裂。
  曾尝试直接重画眼睛，实际近景出现贴纸感，已撤除该尝试。
- 保存三份带完整手表面的可编辑
  `assets/characters/{lin,mei,noah}/athlete-hand-face-prototype.blend`。
  它们是绑定静态源；运行时手指形态过渡仍在 TypeScript 中。
- 生成对应 `public/portraits/prototypes/{lin,mei,noah}.png`，
  没有替换正式角色选择头像。

## 仍不合格的部分

1. 前臂替换面与原上臂的材质、轮廓接合在极近距离仍可辨认；
   尚未达到参考的连续一体化美术质量。
2. 手指可辨识并围住拍柄，但仍是简化圆润形态，不是精细雕刻手。
3. 面部阴影与硬折线减轻，原 UV/脸贴图仍偏糊。没有把低清贴图
   宣称为参考级高清五官，也没有完成庆祝面部动画。
4. 未将样板推广到其余七人，也未替换正式比赛模型。
   下一步应在 Blender 中完成前臂接缝重拓扑、统一皮肤贴图和高清五官，
   而不是继续靠加厚肘部几何遮住接缝。
