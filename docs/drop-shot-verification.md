# 短慢滑动放小球（2026-09-29）

## 用户问题及复现

短而慢的滑动仍飞得很长，用户希望放小球。检查发现：

- 原最短非发球目标也在网后2.8米；40px/650ms的普通滑动目标约3.04米，没有小球专用处理。
- 高触球自动将力度抬到至少0.75。全99球员在短滑高球上可超过20m/s。
- 普通地面弹跳保持横向速度、使用0.72回弹，小落点之后仍向底线跑，不像小球。
- Controls原先要移动12px才认定开始滑动。25px/1000ms的持续慢滑会被误算成500ms静止蓄力，产生约0.27上旋，掩盖轻放意图。
- 出界未必是深度：边线附近的斜向手势还可能从侧面出界。此轮不夹取横向落点，不撤销上一轮的屏幕方向修复。

## 修改规则

- `dropStrength` 从服务器验证后的深度与力度推导，不接受客户端强度标记：深度≤0.13、力度≤0.16时完全轻放，分别在深度0.32、力度0.38前平滑消退。显式高吊、上旋、暴击不触发；发球完全不改。
- 完全小球深度为 `1.15 + depth × 4` 米，典型25～70px慢滑约网后1.15～1.65米；中长球回归原公式。
- 小球的高触点保留可达的举拍动作，但不强制加力扣杀；角色过高的球速系数会在轻放时向普通速度收回，低速角色不会被额外增强。
- 小球落地横向速度保留32%，竖向回弹减半且不高于3m/s；与非小球平滑混合。切削效果先结算，再执行小球吸能。
- 救球/切削的深浅随机变化随小球强度收窄，完全轻放时为原幅度10%；救球减速和既有概率、体力成本保留。
- 自动跑位、等待弹跳预测使用同一回弹函数，避免把球员引向不存在的深落点。新分、普通下一拍、旧快照会清除小球状态。
- 首次移动判定从12px降到3px，减少慢滑误蓄力；原本按住再划的上旋仍通过回归。
- 手势提示显示“放小球”，帮助与来球提示已更新。
