# 高压/截击/上旋 Implementation Plan

**Goal:** 完整接入两种接球技能和可见蓄力上旋操作。
**Architecture:** shared球飞行参数、技能判定/拦截预测独立模块；Match保持权威判定；Controls维护手势与高吊选择，Athlete表现既定动作；预测共用旋转规则。
**Tech Stack:** TypeScript/Rapier/Three.js/Node WebSocket。

- [x] 失败回归：高压、反手/服务线截击、长按上旋；先定位旧行为。
- [x] 权威高压/截击拦截与匹配动作；新增物理及预测统一上旋。
- [x] 蓄力指示、高吊按钮、球路颜色/技能提示和帮助接入。
- [x] 球拍/模型、物理/预测、非法输入、两端一致与整场测试；独立复核。
- [x] 手机布局及动作浏览器验收，更新服务、证据和主清单，提交并推送。

- [x] 追加切削：下划反向投影、独立正反手动作、服务器落点误差和随机低弹跳、两端一致性及互斥输入校验。
