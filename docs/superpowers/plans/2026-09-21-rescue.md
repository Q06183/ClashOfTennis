# 极限救球 Implementation Plan

**Goal:** 在现有权威网球模拟中添加可见、有限距离的概率救球。
**Architecture:** 独立rescue辅助模块负责预测、位移与姿态参数，Match执行抽签/实际触球/随机目标；PlayerState和BallState传递结果，渲染不抽随机数。
**Tech Stack:** TypeScript, Rapier, Three.js, Node WebSocket。

- [x] 先添加失败回归：真实Match输入与飞行、固定随机成功失败、每球一次、合法窗口、减速偏移和双座位。
- [x] 实现rescue模块、类型和Match接入；正常接球优先，恢复期限制，点重置清除。
- [x] 为动作接触/起跳恢复添加测试，再接入Athlete，更新帮助和事件提示；快照插值保留时间一致。
- [x] 完整测试/构建、独立复核、双端协议和浏览器检查；更新主清单证据。
- [x] 重启生产规则服务，确认入口可用，提交本地回滚点，告知双方刷新重建房间。
