# 极限救球

用户要求：有概率跳过去救球，救回的球明显变慢且轨迹随机偏移。

采用主动滑动后自动判定的极限救球；无须新增按钮。正常可接优先。来球在己方合法击球窗口内、常规跑位无法及时够到时，若预计触球位置允许最多 2.5m 的额外跳步，每记来球仅抽一次概率；重复滑动不能重抽。接发球必须落地，二跳或判出界后不能救。

## 2026-09-28 用户修订：体力概率与四类动作

- 满体力 60%；剩余体力 1/3 及以下为 5%。中间令 `t=clamp((stamina-1/3)/(2/3),0,1)`，概率为 `0.05+0.55*t*t*(3-2*t)`，连续且两端斜率为零。
- 取符合救球资格时、扣除起跳消耗之前的当前体力。体力低不完全禁用救球；每次来球仍只有一次抽签。未满足可救范围、无滑动或普通动作能接到时不抽签。
- 正手飞身、反手跃步、腾空截击、跃起高压四类动作；服务端决定类型和正反手侧并同步。保留左右手镜像，反手救球使用单手伸展以获得额外范围；普通双反动作不变。
- 预计触球高度范围 0.35～3.05m，正常高度判定仍执行；起跳最高抬升正反手 0.34m、截击 0.38m、高压 0.62m。高压使用剪刀步腿部交换，截击短引拍，正反手各自转肩和随挥。

Match 使用可注入随机源，线上只由服务器抽签和生成偏移。成功启动后玩家真实位置用约 0.20s 跳向预计接球站位，至少腾空 0.10s 后且实际球拍可达才击球，无瞬移或隔空触球保证。起跳/伸拍/落地恢复总计 0.78s，额外消耗 0.1 体力（最低为零）。

救球沿玩家原目标随机偏移x±1.6m、深度±1.8m，允许出界；以普通档基础弹道增加1.7倍飞行时间，水平速度约减41%，不叠加强力/暴击。偏移发生在击球时，后续遵循正常物理抛物线；预测线展示实际新弹道。球状态带救球标记，事件提示极限救球，角色携带动作时间与起止位置；单机和联机共用。

验收：概率上下限、中间值、连续性和斜率，可控随机测试成功/失败/重复输入、双座位、无输入/接发球未落地/二跳禁止、触球距离、减速与偏移、状态重置；四类型实际蒙皮模型检验跳跃、落地、球拍接触和骨骼有限性。真实 WebSocket 验证双端状态一致及概率由服务器决定。服务器规则更新需要重启 7470，旧房间需重建；GPU 浏览器和真人概率/动作手感仍单独验收。
