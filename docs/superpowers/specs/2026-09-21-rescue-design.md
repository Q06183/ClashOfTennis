# 极限救球

用户要求：有概率跳过去救球，救回的球明显变慢且轨迹随机偏移。

采用主动滑动后自动判定的极限救球；无须新增按钮。相较纯自动救球可保留玩家输入，相较必定触发不会消除跑位价值。正常可接优先。来球在己方合法击球窗口内、临近擦身、常规跑位无法及时够到时，若预计触球位置允许最多1.8m的额外扑步，每记来球仅抽一次35%概率；重复滑动不能重抽。接发球必须落地，二跳或判出界后不能救。球高度限于可扑救的中低球。

Match使用可注入随机源，线上只由服务器抽签和生成偏移。成功启动后玩家真实位置用约0.16s扑向预计接球站位，仍在实际触球范围内才击球，无瞬移或隔空触球保证。起跳/伸拍/落地恢复总计0.65s，额外消耗0.1体力。

救球沿玩家原目标随机偏移x±1.6m、深度±1.8m，允许出界；以普通档基础弹道增加1.7倍飞行时间，水平速度约减41%，不叠加强力/暴击。偏移发生在击球时，后续遵循正常物理抛物线；预测线展示实际新弹道。球状态带救球标记，事件提示极限救球，角色携带动作时间与起止位置；单机和联机共用。

验收：可控随机测试成功/失败/重复输入、双座位、无输入/接发球未落地/二跳禁止、触球距离、减速与偏移、状态重置；渲染检验跳跃、落地、球拍接触和骨骼有限性。真实WebSocket验证双端状态一致；手机尺寸浏览器检查模型和提示。服务器规则更新需要重启7470，旧房间需重建；真人概率与动作手感留待试玩。
