# 全动作与特殊球员

## 范围与选择
沿用程序骨骼、真实触球 IK 和现有资产。优先修正连续运动和全身协调；引入动捕素材会增加授权、重定向和触球校正成本，本轮不冒称动捕。动作参考 USTA 教学图解、ActiveSG/Stefanie Tan 截击和 Feel Tennis 单反教学，独立编排关键姿势。

- 正手：转肩、降低拍头、蹬地、向前向上、对侧肩随挥。
- 双反：双手保持握柄、髋先转、延伸后肩上收拍。
- 单反：引拍时辅助持拍、向前释放、非持拍臂反向平衡、保持侧身。
- 截击：短引拍、上步挡击；切削：高到低向前送拍；高吊：屈膝向上托送；高压：侧身指球、头顶触球、向前随挥。
- 准备/跑动/后退/侧移：位移驱动步频与支撑脚，疾跑释放非持拍手，减速回到持拍准备；救球：伸拍、反向平衡和落地缓冲。
- 发球沿用已验收连续曲线，补齐左右手与一区/二区的正确镜像。

新增三名球员：诺亚（左手双反，正手进攻）、阿德里安（右手单反，反手进攻）、露卡（左手单反，网前全场）。六项属性预算仍为 360。使用现有自有生成模型制作本地服装变体并记录来源，不新增外部付费生成。模型、头像、选择介绍均须实际显示。

利手来自服务器验证后的角色 ID。正反手判断、自动站位、接触可达性、救球、技能和渲染统一使用该信息。单反只去掉第二只手的物理约束，不提供虚构范围加成；接触仍要求拍面真正到球。滑动指向始终以屏幕为准，不随利手翻转。

## 实施与验收顺序
1. 先加失败回归：左右手镜像接触/跑位、单反第二手释放与正反手属性；角色目录和平衡预算。
2. 改 characters、skills、reception、rescue、match，渲染在无反射坐标中求 IK，最后镜像整个人物，避免负缩放污染四元数。
3. 非发球统一连续运动曲线，分别编排单反/截击/切削/高吊/高压的随挥与身体链条；跑动和救球的辅助臂与头部协调。
4. 本地服装变体、头像与角色 UI；真实 GLB 检查。
5. 双座位/全部动作/全部利手类型测试真实触球、手柄约束和连续性；真实比赛检查穿模；浏览器前/侧/背面与手机画幅检查；网络两端新角色对局。
6. 全量测试、构建、代码复核、更新主验收清单；提交并推送当前仓库的 main 和 codex/friends-tennis。手机观感仍由下一次真人试玩校准。
