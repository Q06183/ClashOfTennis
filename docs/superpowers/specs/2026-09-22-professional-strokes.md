# 全身击球动作与两倍近景

用户目标：每个姿势正确对应，发球尤其需接近专业运动员；正手、双手反手、正反手切削、截击、高压、高吊明显可辨；人物和场地视觉放大约一倍。

诊断：旧动作以拍头位置为主，发球预备时shotQueued=false导致屈膝未进入腿部；自由手共用位置，站姿两脚平行、发球双脚同时升降；抛球不依赖真实释放轨迹，发球/高压完全共用模板。旧模型接触测试只证明拍面够到，不能证明动作专业。

方案：保留真实生成的六个GLB，用完整分阶段动作驱动骨骼并保留拍面接触IK。独立的球拍/躯干/骨盆/脚步/平衡手/拍面转动通道；发球加入侧身平台站位、抛球伸臂、奖杯姿势、屈膝蹬地、落拍、伸展触球、内旋、前脚落地和后腿回收；高压使用缩短的举拍下压而不抛球。正手低到高绕肩，反手双手转肩伸展，切削单手高到低后向前送拍且平衡臂展开；截击小引拍、前脚迎击。跑动和不可达预备保持现有保护。

镜头：通过更低、更近的透视与跟随令底线球员及其所在场地局部线性尺寸约2倍；两侧相同，保留对手/球网/自己可见，越界跑动仍可跟随。物理尺寸不改，避免改变跑速/触球距离。手机正常竖屏为主要验收对象，横屏保持可操作。

证据：发球抛球实际连续轨迹、两脚与蹬地时序、球拍/握拍接触连续；动作路径/自由手/躯干有可测区别；六模型所有阶段无爆面和穿模；390×844和小手机/横屏视口、两端投影和实际游戏录帧/慢放；全套测试/构建/双客户端比赛，再启动7470，保存并同步仓库。视觉审查逐动作且以真实模型为准；不能以拍面误差与测试全绿代替动作自然度。

参考：[USTA 教学手册](https://www.usta.com/es/content/dam/usta/sections/southern/pdf/net-generation-high-school-team-tennis-manual.pdf)、[USHSTA 切削上网](https://ushsta.org/slice-approach-shots/)。原创程序动画，按动作要点实现，不复用原游戏专有资产。
