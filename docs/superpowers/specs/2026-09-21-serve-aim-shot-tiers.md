# 发球方向与四档球速修订

用户反馈：发球滑动方向与实际球路不一致；暴击过于容易，同滑距应比强力更深、更易出界；增加快速球和各档路径颜色。

## 行为

- 普通（绿）→快速（蓝）→强力（橙）→暴击（玫红）；高吊维持独立紫色。
- 速度由归一化滑动速度连续控制；暴击要求未长按、较长且极快甩动。速度计算至少按120ms，避免极短事件时间把小动作放大为暴击。
- 同一滑距下，档位越高落点越深；不把目标截回边界内。落点越界/发错区以红圈提示，路径仍保留档位颜色。
- 拉开滑距的深度控制范围，让受控长度的暴击发球仍可合法，继续滑长增加出界风险。
- 发球从实际2.65m头顶触球点投影，结合当前档位目标深度求世界方向；发球抛球阶段短暂锁定镜头跟随，防止瞄准之后画面漂移。两座位和两侧发球区一致。
- 服务端派生档位并同步；客户端反馈、预测轨迹和拖尾共享颜色定义。加粗预测线至3px，手机上更清楚。

## 参数

暴击：hold<180ms，距离≥0.58短边宽度，速度≥5.2短边宽度/秒；120ms计时下有效最短长度为0.624短边宽度。普通/快速/强力的power分界为0.38/0.7；暴击还需power≥0.9且不是高吊。

深度：基础回合2.8+8.6d，基础发球3.4+2.6d；各档深度附加量见src/simulation/shot-profile.ts。固定d=0.8时，强力回合落点10.785m、暴击11.955m，前者场内而后者超底线；强力发球6.065m、暴击6.78m，后者超发球线。

## 验收

- 发球手势屏幕方向与实际权威弹道落点投影一致。
- 真实手势→相机映射→服务端模拟→预测落地，全链路保留合法暴击发球窗口，覆盖三种屏幕与四种发球顺序。
- 较短的旧暴击手势现在不触发；同滑距不同时长能覆盖四档。
- 路径颜色双方一致，出界提示单独标红；WebSocket权威档位到达对手。
- 完整规则回归、生产构建、浏览器颜色预览和双客户端完整比赛；真人手感另由用户手机复打确认。

## 手机反馈后的门槛微调

快速/强力的归一化滑速门槛提高约28%，power=(speed-0.4)/3.8；暴击另要求有效甩动≤100ms，原hold、长度、速度条件保留。深度映射不变，既有合法暴击发球全链路验收继续通过。

### 再次收紧强力球
