# 高压球、灵敏截击与明确上旋

目标：用户可对头顶高球打高压球，改善网前截击；替换未知的长按高吊为可见蓄力上旋。

- 高压：实际合法头顶触球时自动选择，不增加概率。只在非接发未落地的合法来球中启用，高度>=1.85m、下降/缓升球、球拍真实可达；专属举拍-下压-随挥、较快球速、金色球路/高压提示。不能远距离隔空打球。
- 截击：第一次落地前可合法截击，去掉旧站位6m硬门槛；接发必须先落地。单手反手截击不套用双手反手范围。网前（服务线附近）预测拦截点，辅助横向就位，不主动退回底线，仍受实际移动和触球范围约束。保持160ms同来球容错及二跳/出界判定。
- 蓄力：按住350ms开始上旋，900ms充满，滑动释放；长按不再隐式高吊，HUD显示蓄力条和上旋文字。上旋增加向下加速度、弧线和落地前冲，预测/真实物理/接球预测/联机短预测使用同一重力参数。明确为街机简化旋转模型，不宣称完整空气动力学。
- 高吊：底部小按钮选择“下一拍高吊”，再滑动，发出后复原，可再次点击取消；提示清楚。保留高吊来球以供高压应对。
- 服务端决定技能、旋转量/球速/颜色，校验有限数并限制旋转0..1。客户端不能强制高压，发球/救球/截击不混入不适合的动作。
- 验证：测试先复现旧反手截击和6m限制及长按高吊；双边高压实际触球与下降速度/拍面接触，旋转轨迹/落点/反弹，输入清理/非法值，所有角色动画、真实WebSocket一致性、手机HUD及动作预览。整场比赛正常结束/再赛。完成后更新运行服务与主清单，保存提交并同步指定仓库。

## 追加：正手与反手切削
前述技能检查后加入：向下划，屏幕方向取反后通过当前相机投影；左右两位选手遵循相同规则。切削覆盖蓄力和高吊选择，回球时单手高到低切拍，按来球侧选正手/反手；发球仍用发球动作和普通旋转。冰白球路。飞行减速，目标横向误差±(0.4+0.65×力量)m、纵向±(0.5+0.45×力量)m，可出界；首次合法落地后航向随机±0.16弧度、水平保留80–92%、反弹向上速度保留58–78%。随机由服务器生成，两端展示同一结果，球路预测显示实际已生成落点；落地前不预知随机侧偏，落地后重新预测。高压/救球优先，不叠加互斥旋转。
