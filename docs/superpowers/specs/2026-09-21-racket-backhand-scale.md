# 近景、球拍尺度与双手反手修订

用户明确要求人物和场地一起再放大，纠正球拍比例与反手姿势。

- 保持物理场地和人物身高，收窄比赛视角，让人物和场地共同增加约15%占屏；检查近侧跑位、后场跟随和小屏安全区域。
- 当前程序球拍约1.05m长、0.53m宽，超过成人常用27英寸球拍。重做为约0.685m长、0.284m宽；握点到甜点0.45m，双手间距0.10m。统一动画和模拟的触球可达范围，避免小球拍仍用旧远距离击球判定。
- 双手反手使用独立转肩、引拍、拍头下落、向前上方伸展和右肩随挥路径；持拍两手持续贴合，触球仍定位真实球位。发球加入小幅起跳，匹配缩短后的球拍触球高度。
- 单测核验球拍实际尺寸、全程双手握点间隙、真实回合触球一致和镜头可见性；浏览器逐帧检查正面/侧面/背面和手机主游戏。更新运行版本并回归完整网络对局。

参考：Wilson球拍选购指南（标准成人27英寸）；USTA Net Generation双手反手教学（转肩、低到高挥拍、延伸和随挥）。保留现有Lux3D模型，无新增消费。
