# 场地比例与有重量的跑动

用户反馈人物相对球场偏大、覆盖场地太轻松、跑姿不真实。

核验：场地与判定均为 23.77 × 8.23m 单打尺寸，模型原始站立高度 1.96m。无需把物理场地任意放大。近端透视放大、瞬间满速和固定频率摆腿共同削弱了距离感。

实施：
- 使用更远的镜头与更窄视角，保持场地占屏宽度，降低近端人物相对球场的放大，保留上轮边线/后场跟随和手势投影。
- 服务器移动加入速度、加速、制动和到位停车；侧移5.2、前跑5.8、后退4.3m/s上限随体力变化。客户端不以固定速度预移人物来绕过服务端加速。
- 腿部由实际移动距离驱动步频，支撑脚在世界坐标落地，摆动脚抬起；双段腿IK和独立脚踝保持鞋底朝地，上身有轻微重心倾斜，击球接触继续对齐真实球位。
- 重新验证接球可玩性、双端一致、急停反向、足底稳定、重置不假跑，以及手机场地构图。

边界：这是本地骨骼动画迭代，不使用新的生成预算；不宣称专业动捕或真机手感已验收。
