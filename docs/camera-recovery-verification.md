# 近远视角与救球落地恢复

日期：2026-09-28

## 实现

- 比赛右下角新增“近景 ⇄ / 远景 ⇄”按钮。近景默认，远景保留完整球场；两者均为正后方，物理比例/球速不变。
- 选择通过 `rally-camera-distance` 保存；读取失败默认近景，写入失败当前会话仍切换。
- 若正在滑动、预设击球或本方出球锁镜头，先记录选择，锁结束后应用，避免瞄准中改变投影。
- 近景采用较低机位与 32° 起始视角，并根据双方人物可见性自动放宽；远景采用原完整场地构图。
- 救球从起跳 0.48s 起落地，屈膝/上身前倾缓冲约到 0.68s，再平滑起身到 1.18s。
- 总硬直延长至 1.18s，期间不能移位或再次触球，可预留下一拍输入；落地后的未命中救球也不能继续凭空碰球。
- 得分发生在腾空中时不立即清掉救球动画；分间继续落地起身，下一分再重置。最终得分结束仍可推进未完成恢复，不再冻结在空中。
- HUD 显示“落地缓冲中 / 正在起身”，帮助面板说明延迟。

## 验证

- 近远距离差异、两座位后方机位、两套完整落点方向、切换延后、生存期与本地存储失败回归。
- 原全员全场方向测试分别运行近/远模式；近景不绕过真实触球投影。
- 落地根节点归零、髋部下沉/抬起、分结束不中断动画、连续性和实际 GLB 约束测试。
- 两条真实 WebSocket 在 0.68–1.18s 内收到相同恢复状态，移动/击球不能绕过硬直；恢复后状态清除。
