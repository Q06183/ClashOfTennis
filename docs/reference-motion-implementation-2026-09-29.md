4. **控制器接入**：腰胸分配旋转、肩部前伸、脚趾变形，手臂仍固定
   长度；保持触球肩心位置，不扩大判定半径。16 骨骼历史模型回退测试通过。
5. **首批动作修改**：
   - 正手、单/双反手共享蓄力—停顿—加速时钟；未排队出拍时身体和
     球拍都停在蓄力阶段，不再球拍等待而身体先打开。
   - 向前跑动在前掌支点抬后跟，脚趾反向补偿保持支撑朝向；
     后退/横向调整不套用向前蹬离。
   - 救球分为 `step-out` 和 `supported-fall`。前者非对称落脚，
     不把双手压到地上；后者保留撑地恢复。
   - 服务端将较短（横移 <1.8m）且较高（触点 ≥0.85m）的救球选为
     step-out。**这两个阈值是实现选择，不是从录像推算出的统计规律。**
   - 保留自然侧扑移动、0.5s 补滑定格和原恢复锁定时长。旧快照未携带
     recovery 时仍采用 supported-fall。

## 检查中修复的回归

- 无名有额外图片 bufferView，新权重的文件偏移不应与 Lin 相等：
  改为逐 accessor 的实际数据核对，仍严格验证几何/关节/权重相同。
- 旧跑步测试要求鞋底始终水平，与抬后跟冲突：
  保留膝旋转隔离，验证后跟角 ≤0.281rad、前脚掌水平与支点稳定。
- 救球起身后视觉根节点的髋轴偏移被当作跑动：
  离开救球时重置步法状态，避免凭空出现高抬腿。
- step-out 不再使用为趴地翻转设计的拍杆径向修正，避免恢复早期腕部跳动。
