# 正反手姿势跳变修复 — 2026-09-30

## 已定位的原因

1. `preparationPhase` 在未缓存击球输入时将进度截在 `.6`，映射后停在 `.52`；输入到达时改用当前预测进度，跳过中间动作。固定 `.96` 进度、只切换 `shotQueued`，原版正手拍头跳变 0.884m / 躯干转动 48.05°，反手跳变 0.752m / 27.34°。
2. 正反手时间曲线在 `.54–.68` 完全静止，随后快速追赶；该静止段约 91ms。身体和球拍都受影响。
3. 收拍期间跑动混合权重一直为零，`swing` 归零后突然恢复。6m/s 回位夹具中，最后一帧正手/反手拍头相对人物分别跳变 0.316m / 0.340m。

## 修改

- 正反手引拍时钟与 `shotQueued` 解耦，躯干和球拍继续共用单调、C1 连续的时间曲线；保留缓慢加载和触球端导数，不再完全停住。
- 可及的身后触点渐入同样不受正反手输入开关控制；不可及触点仍保留保护。
- 正反手最后 120ms 收拍逐渐混入跑动；实际触球和主要随挥段不受影响。
- 不改本轮涉及的击球规则、服务器判定、球路、角色属性或模型文件。工作区原有模型、救球等未提交改动均保留。
