# 偶发出球大偏角修复（2026-09-29）

用户反馈：偶尔仍严重偏离手指滑动角度。本轮针对未覆盖的异常分支，不改镜头、救球动作、体力与触发概率。

## 复现和原因

1. 救球／切削先求解方向，再给目标横坐标加随机偏移，破坏了已求出的屏幕方向。旧测试多使用随机中值0.5，偏移恰为零。专项用随机两端复现；直划救球可偏约21度。
2. 原方向求解在横向斜率-4至4内搜根，每次修改落点又重算飞行时长。慢球、疲劳、侧扑减速、高吊可能让角度函数不再单调或无根，随后悄悄回退到身体中心旧公式。扫描中出现约60度误差。
3. 不能通过扩大搜索范围草率解决：同样的滑动可能找到多条高低不同的弧线；微小手势变化会跳到另一个根。

## 修改

- 触控击球先用纵向距离、深度、体力、球速属性、球种、过网高度与救球减速确定飞行时长，再解析求解实际触球点到前100毫秒球位置的屏幕射线。横向瞄准后不再重算时长，也不再使用有限范围搜根。
- 手势指定方向时，取消救球和切削的随机横向偏移；保留深浅波动、减速、体力成本、切削落地后侧偏。既有随机采样序列保持稳定。
- 极斜手势仍可打出界，没有把落点夹回球场。相同深度的触控球现在共享纵向飞行时间；斜向分量独立求得，因此横向球速随手势变化。这是消除方向／时长循环依赖的明确取舍。
- 老客户端／无屏幕投影的AI指令保持原行为。正常手机页面发送投影，应用新规则。帮助文本已同步。
- 保留物理重力：承诺出球方向匹配，不把整个抛物线变成屏幕直线；切削弹跳后的侧偏仍是球种效果。
