# 救球覆盖率第一轮：稳定窗口、提前准备、顺势及短侧扑

用户确认实施前三项，**体力概率不改**。

## 实施范围

- 普通回球的未来预测需连续 **100ms** 合法可接才否决救球；不是找到一个
  擦边采样点就判定“肯定能跑到”。当前已经够到的合法普通击球仍立即优先。
- 保留普通接发球策略原有50ms判断；仅救球否决使用100ms，避免重写普通打法。
- 候选触球搜索由 .24～.72s 扩至 **.16～.90s**，不再按球速<3m/s排除低速紧急球。
- 没有立即可行的侧扑时，最多预演240ms正常跑步，提前调整位置；仅在正常
  自动跑位许可下生效。预测不移动真人、不抽签、不授予触球。
- 有充分余量时先正常跑位再起跳；每次起跳前仍从实际状态重算。准备计算
  最多每80ms一次；落地、手动移动、换球/换分清除旧方案。
- 继承真实起跳横向速度，三次Hermite轨迹连续减速、转向及落地。
  计算速度/加速度极值及整条曲线位置边界，而非只检查终点。
- 最大横移3.5m、最大速度9m/s、最大加速度65m/s²、空中前后坐标固定。
- ≤1.2m的短救球使用跨步落地，触球/落地阶段不缩短，只加快落地后恢复。
  新短扑需两个相隔约33ms的可接预测采样；原长扑保留原实际触球约束。
- 总体力概率曲线、每球一次抽签、真实球拍触球、.5秒补滑、失效不倒带均保留。
- 出手无随机角度偏移；**切削落地随机横向转向保留**。
- 不改人物模型、肌肉纹理、外观、属性或球场比例。

## 对照结果（不是实际玩家频率）

`scripts/verify-rescue-coverage.ts` 对比本轮修改前源码副本，216个固定输入场景，
覆盖4档横向距离、3档球速、3档到达时间、3种初始速度、2档体力。
随机数固定成功以隔离“可进入候选”的能力，**不是把线上概率改为100%**。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 初始时刻可行候选 | 54 | 130 |
| 实际飞扑并触球 | 47 | 66 |
| 其中短扑 | 0 | 7 |
| 飞扑后未碰到球 | 0 | 0 |
| 包含普通回球的总成功数 | 141 | 147 |
| 峰值飞扑横移速度 | 8.571m/s | 8.924m/s |

按初始横向速度拆分实际飞扑触球：
- 静止：14→26。
- 朝来球方向跑动：6→16。
- 反方向跑动：27→24。

新增33个飞扑触球场景；同时失去14个旧版可接场景，全部属于反方向奔跑。
原因是旧版忽略起跳速度，可瞬间抹掉反向动量；新版保留减速时间且不突破速度、
加速度或横移上限。不能声称覆盖集合完全包含旧版，也不能把66/47直接宣称为
玩家实战触发率增幅。
