# 扩大飞身救球范围（2026-09-29）

用户要求扩大救球范围，而不是提高概率。本轮保留左右侧扑、普通方式可接优先、体力概率和落地起身延迟。

## 变更

- 人物单次侧扑最大横移：2.5米 → **3.5米（增加40%）**。这是人物横移距离，不是球拍触球半径。
- 候选轨迹的距离/时长限制系数：13 → 18米/秒。该数值不是峰值速度；当前侧扑采用缓出曲线，瞬时速度随进度变化。只改距离上限会让200ms动作仍被旧2.6米限制挡住，因此两处同步调整。
- 预测时间仍为0.12～0.28秒，普通首选0.20秒；不延长腾空或硬直。
- 手臂长度、球拍物理接触判定、前后位置、场地边界与越网/二跳规则不改，不把球传送到拍面。
- 总体力满时90%、1/3及以下10%的概率不变，每次来球仍只抽一次；普通走位能接到的球不救。
- 0.68秒开始起身、0.5秒起身过程、1.18秒恢复操作不变。小球与方向修复保留。
- 游戏帮助同步标注3.5米人物横移上限。

## 验证

- `tests/rescue-range.test.ts` 先在旧版复现失败：3.65米横向来球无候选，也不进入抽签。
- 扩大后：林、诺亚、无名 × 双端 × 正反手/截击/高球，均在旧2.5米横移范围以外完成合法回击。测试加载实际GLB，球拍甜点与真实触球点误差小于0.1米；前后位置保持不变，逐步横移无瞬移。
- 不满足概率仍失败且只抽一次，5米横向不可达球仍不进入抽签。原普通接球优先、接发先落地、二跳终止和起身测试继续回归。
- `tests/rooms.test.ts` 新增扩大范围双WebSocket测试，双端正反手在旧范围之外起跳、触球，同序号权威快照一致。
- `scripts/assets/rescue-preview.ts` 新增 `RESCUE_PREVIEW_GAP`，可从真实模拟导出3.65米来球的左右手四类姿态。CPU预览不等同于浏览器GPU或手机真人试玩。
