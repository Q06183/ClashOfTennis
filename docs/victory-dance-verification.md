# 轻街舞胜利庆祝（2026-09-29）

用户已选择“轻街舞庆祝”：站稳握拳 → 左右侧踏并步、轻微摆肩 → 举拍致意 → 自然站定。本轮只修改渲染；自动救球后的0.5秒补滑机制没有实现或改动。

## 旧动画的问题

- `abs(sin(...))` 驱动身体每半秒反向，反转处纵向速度从约-0.69跳到+0.69米/秒，产生明显弹簧感。
- 根节点上抬时又抬单脚，支撑脚也跟着悬空，不像承重舞步。
- 手臂、双脚、身体各用不同相位循环，动作没有起承转合。
- 庆祝仍经过普通发球/击球渲染分支，上一拍状态可能改变非持拍手。
- 原结算镜头投影中，竖屏脚底落在约76%屏幕高度，会被底部结算面板遮住。

## 新动作

- 5.2秒有限动作序列，结束后固定自然站姿，不重复跳舞。
- 0～0.7秒：从上一个姿态用0.45秒平滑过渡，站稳、抬臂握拳庆祝。
- 0.7～3.05秒：左右侧踏并步，各脚起落独立；膝盖小幅屈伸，髋部转移、肩部轻律动。根节点不再上下弹跳。
- 3.05～4.15秒：平稳举拍、停留致意。
- 4.15～5.2秒：收拍回自然站姿。
- 躯干关键帧使用五次平滑插值，转段速度/加速度为零；脚底目标相对初始站位，支撑脚不会跟着重心平移。
- 通过原固定长度IK、实际球拍和真实GLB骨骼实现。持拍手不甩到身后，非持拍手不再受上一拍发球状态影响。手指仍为既有模型的简化手形，不是手指动作捕捉。
- 左右利手与双端方向一致；从比赛跑动或救球切入有姿态过渡，重赛会清除庆祝状态。
- 只调整结算镜头：竖屏人物全身放在标题与底部卡片之间，横屏放在右侧卡片的左边；比赛近／远机位不改。
